# 博士服教棍 · V1

作者穿博士服，教棍从右下举向右上，再沿原路径返回。素材按用户指定的既有序列帧原样复用。

- [动画预览](preview.html) · [序列总览](overview.png)
- [帧尺寸、锚点与动画清单](manifest.json) · [原素材验收记录](validation.json)
- 透明画布 512×512，共 16 帧，8 fps，循环 2 秒；首尾和反向返回帧一致。

这是手绘关键姿势序列，可能保留轻微脸部、衣服和轮廓差异，不应当作已通过骨架动画认证的素材。使用时读取 manifest 中的帧率和路径，保留固定脚底锚点，并为完整教棍摆动预留空间。

动画预览直接读取透明 PNG 序列；APNG 衍生文件已清理，序列帧像素和帧序保持不变。
