# 作者序列帧与参考音色

## 缓存优先与版本

先阅读根目录 `assets/README.md` 与人物库 manifest。当前闭嘴版是 `assets/手绘形象/shikanon-animation-v3/`；早期 V1/V2 包含历史生成帧和配准底稿，不应作为当前嘴型。原始作者形象是 `shikanon-儿童手绘-v1.png`。

V3 有讲解、指向、思考、领悟、挥手、问号思考、教棍、轻步八组动作；每组 24 帧、20 fps、1.2 秒，单帧 384×576，图集 6×4。实际复用读取 manifest，不把这些尺寸或动作数写成跨项目常量。旧 ID `talk` 在此版本只表示讲解手势，不表示嘴部动画。

每个动作提供透明 PNG 序列、atlas、动画 WebP、预览页及元数据。视频中保留副本，根目录公共库保留一份；用 SHA-256 核对两份内容，后续直接复制。新增动作才生成或绘制，并记录参考、提示词、工具、来源与版本。

## 消除抖动，同时保留自然动作

统一透明画布和解剖锚点：至少记录脚底基线、身体中心与头部基准。只按每帧外接框中心对齐会把举手、道具伸出造成的框变化传给整个人物。

同一角色的衣服、躯干比例与轮廓固定；手、脚、头部绕稳定关节做平滑运动。头可点动或歪动，脸和嘴随同一颗头整体刚性变换，保持闭嘴微笑。不要单独替换嘴、开口或做嘴部形变。对有头部动作的帧，核对“相同头部经过相应变换”后的嘴部，而不是要求屏幕上的嘴坐标永远不变。

四肢提取使用明确蒙版，特别注意自然下垂的手掌可能低于腰线：不能把它一起裁到腿层，否则迈步时会出现多余手掌残影。手握教棍时棍子跟随握点；手势不要遮住脸。问号属于独立道具，可轻弹或摆动。

动作间用共同中立姿势或短过渡；循环首尾匹配。各关节插值平滑，画布留足安全边距。不要用随机抖动模拟活泼，也不要通过冻结整个人物掩盖抖动。

验收原始 PNG、浏览器时间线和编码后 MP4 三层结果：骨架无非预期位移、固定嘴型一致、实际手/脚/头确实变化、工具无残影、正反向 seek 都使用正确帧。V6 的 `rig_author.py`、`verify_rig.py`、`verify_encoded_stability.py` 和 `sync_author_library.py` 提供可借鉴实现。

## 参考音色与 Seed Audio

用户指定 `assets` 内参考声音时先定位实际音频、确认可读、探测长度和格式，并记录输入哈希。参考声音可能在另一工作区；只有找到真实文件才可声称已使用。未经本次发布要求，不把参考声音本身公开到 Git 或对象存储。

使用可用的 Seed Audio `generate_audio`。先读取服务能力与当次工具参数，按其支持的 reference 格式传入音频；本案例 `references.audio_path` 与提示词 `@音频1` 用于指定作者音色。只借鉴音色，解说文本来自当前脚本。不要把其他 TTS 音色悄悄代替指定参考。

按服务限制和自然段分段生成，记录脱敏请求、任务 ID、实际生成文件、服务字幕及词时间。试听发音、数学术语、断句与噪音。合并前校准响度和停顿，配乐/效果声压低，不遮盖解说。

快节奏以实际语音计量，当前默认约 320 汉字/分钟。必要时对单段使用保持音高的 `atempo` 小幅校准，并按同一系数变换词时间；不能仅改字幕或把旧成片整体倍速。字幕采用实际说出的词时间，并补核对音频开头、段间接缝与尾部。原始 ASR 结果与编辑后文案分开保存。

## HTTP 402 的实际诊断

402 本身不能证明“余额不足”。保存已脱敏的 HTTP 状态、业务错误码、模型/资源 ID、请求 ID、额度绑定和服务响应正文；核对额度是否适用于这个模型、这个账户和该资源，以及权限、并发或付费状态。总账户额度多不代表所调用模型资源绑定正确。

丢失历史业务响应时说明无法确定旧错误根因。此案例早期 402 没有保留完整业务正文，后来同一 Seed Audio 流程使用作者参考音频成功，不能倒推旧错误必然是额度原因。

参数/资源配置更正后做一次最小调用；遇到相同错误立即停止重复计费尝试，先取得具体原因。常规瞬时失败采用有上限的退避重试。不要自行购买额度、更换用户账号或暴露凭据。当前只有媒体修复时复用已合格的音频，避免无必要的再次生成。
