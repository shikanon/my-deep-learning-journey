# 时间线、技术栈与成片验收

## 用动画解释变化

每个场景提供观察对象、变化过程与结论。曲线由真实函数计算；参数变化、离群点、概率、梯度等具有统一坐标。计算最小值与画面标记使用同一数据。用箭头、局部高亮、分步揭示、粒子流或缩放指导注意力，给读者看到关键结果的停留时间。

HTML/CSS/SVG + 一条受控 GSAP 时间线适合中文、公式、便签与多数二维图解；Canvas 适合大量点/粒子和连续曲线；WebGL/Three.js 在空间结构、相机运动或三维过程确实有帮助时再用。技术选择不等于质量，更丰富的动效应带来更多可理解的过程。

## 确定性逐帧

将场景、字幕、图解、人物动作都绑定到同一个时间。渲染器要求的接口按现有工程约定，例如注册 `window.__timelines.main`，用 `frame / fps` 定位。任意时间、反向跳转和重复采样应产生同一画面；不要依赖独立 CSS 动画、Date.now 或未受控 requestAnimationFrame。

人物图集按 manifest 的列数、帧矩形与帧率寻址。时钟用工程时间，不用浏览器自然播放时间；开始/结束、循环、跨动作中立帧都明确。根 SVG 的布局选择器要限定层级，如 `.visual > svg`，否则嵌套图集 SVG 会被误扩大，角色消失或裁切。

顶栏包含大章与当前小节进度。成片烧录的顶栏不能接受鼠标点击；单独 HTML 播放器把章节按钮、拖动滑块和键盘定位绑定到真实 `<video>.currentTime`。字幕、安全区、底部项目名称与人物不能相互遮挡。

## 输出与可移植性

本项目默认 1080×1920、30 fps、H.264、AAC、yuv420p、`+faststart`，嵌入章节元数据。可根据渠道要求调整。保存工程、配音、字幕、章节、分镜及构建命令。字体使用本机合法可用中文字体或有明确开放许可的字体；不要把系统商业字体二进制复制进公共仓库。

依赖通过当前环境发现，不在可复用脚本中绑定个人机器路径。使用 Hyperframes 的工程先读取其当地要求，保留可编辑来源。不要把 CLI 渲染结束当成验收完成。

## 四层验收

1. **内容：**正文/口播比例、公式和算例、引用、关键词发音与字幕一致。字幕时间对齐真实语音，不漏头尾和段间接缝。
2. **工程：**重要时刻和边界、所有动作的换帧、循环接缝、正反向随机 seek。检查文本对比度、溢出、角色锚点、固定嘴型和工具握点。报告明确哪些自动检查启用，不能把未开启的 motion 检查写成通过。
3. **实际文件：**ffprobe 检查尺寸、编码、帧率、时长、帧数与章节；FFmpeg 完整解码。抽取最终 MP4 关键帧与动作前后画面对比，检查嘴、身体、手脚与图解；不能只看原始 PNG 或压缩前画面。若比较 YUV420 解码小区域，将裁切原点/尺寸对齐偶数，避免色度偏移污染指标。必要时用正确/错误嘴型作对照，而不是放宽阈值。
4. **真实播放：**当前最终哈希媒体正常速度从头连续播到 `ended=true`，中途不 seek；记录 currentSrc、duration、currentTime、readyState、媒体与控制台错误。再验证所有小节、三大章、拖动和键盘跳转，桌面与手机宽度无横向溢出。片尾项目名称与关注文字在手机缩放后仍然可读，默认确认画面没有二维码。

保留 QA 记录、关键帧和实际播放结论。对可见新缺陷，修正源文件并导出新成片，重新核对实际文件，不沿用旧报告假装新版通过。临时 viewport 验收后恢复。

## 云端验收

上传后检查公开 URL 的 HEAD 类型/长度、Range 206 与完整下载 SHA，并将播放器切到云端 URL，再真实播放到结束。缓冲暂停但无媒体错误时记录并继续等待/恢复；不可仅凭一次超时判断全部失败，也不可把尚未到片尾写成成功。

播放器媒体来源带内容哈希，避免缓存错版。图片、播放器、文章的最终来源与 `publication.json` 一致。可编辑工程保留当地配音，但 Git 不收大音视频和私有参考；公开验证摘要写清这种交付边界。
