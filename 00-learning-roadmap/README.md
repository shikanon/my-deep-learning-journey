# 学习与维护说明

[返回知识总索引](../README.md)

从总索引选择当天想研究的二级知识点，进入该目录查看子知识点。需要某项前置知识时，再回到对应目录补充；目录编号只表示分类。

当前各知识点目录仅建立 README 索引。后续在选定目录中创建正文，已有四篇早期示范保留原文件和入口。

## 新增正文

```bash
# 在仓库根目录运行，Python 3.9+，无需第三方依赖。
python3 scripts/new_note.py 04-large-language-models/positional-encoding 001-introduction 位置编码导读
python3 scripts/check_notes.py
```

正文采用[导读模板](../templates/knowledge-note.md)：为什么提出 → 要解决的问题 → 直觉与原理 → 历史演进 → 关键人物与论文 → 近期研究 → 自测与扩展阅读。

## 每次更新

1. 选择一个二级知识点或其中一个子主题，围绕一个具体问题搜集一手资料。
2. 阅读经典工作的研究动机和方法，再检索该主题的近期论文。
3. 更新同一知识点正文，记录最新检索日期、论文版本、证据与仍未解决的问题。
4. 将正文链接加入当前目录的 README，填写当天的[学习日志](../journal/README.md)。
5. 检查链接与结构后提交；未执行的实验标为待执行，未核验的资料标为待核验。
