# 作者序列帧版 V4

延续奶油纸张、暖橙与青绿的儿童彩铅手绘画风，使用作者的黑发、方框眼镜、白色卫衣与 `shikanon` 胸标形象。本版的重点是人物的嘴型、眨眼与手臂姿势真正逐帧改变。

人物动作分为讲解、指向、思考、领悟与挥手五组。用内置 `image_gen` 生成透明动作图集，切出完整人物并统一脚底锚点。每组保留原始生成图、12 张 PNG、图集、循环 WebP、提示词与配置。先保存到仓库公共素材库 `assets/手绘形象/shikanon-animation-v1/`，再同步到本视频的 `assets/author-animation/`。新视频可直接取用缓存。

开场先讲解，出现答案 6 和 3 时伸手指向卡片，问“为什么”时托腮；Huber 阈值和 DPO 偏好噪声处思考；SigLIP 2 的老师指向、学生讲解；总结时开心握拳；项目片尾先指向，再讲解，最后挥手。十五个背景人物使用错开的动作相位。图解中的负样本推开与大残差限速仍保留有意义的位置移动。

视频采用 HTML / CSS、SVG 图集视口与一条暂停的 GSAP 时间线。图集只内嵌一次、复用 27 个人物实例；人物按 10 fps 离散选帧，整片按 30 fps 渲染。每帧记录动作名、图集位置和姿势帧号，随机跳转与导出选择同一张 PNG。讲解循环降低眨眼频率。嘴型是讲解节奏动画，没有宣称逐音素同步。

内容、原始配音、字幕、解说速度、三秒钩子、30% / 50% / 20% 内容比例与 GitHub 项目片尾沿用已完成的 V3。V4 不重新调用 Seed Audio；通过哈希核验复用的配音字节。顶部章节条持续显示当前小节，HTML 播放器可拖动和点击跳转。

素材预览使用 Canvas，支持五组动作播放、暂停、速度调整、帧滑块与深浅背景。生成结果会有小幅彩铅笔触差异；脚底锚点统一、动作逻辑经过人工检查，未将静态图片平移当作序列帧。思考动作的一个不一致源姿势被替换为本组已有的回落过渡姿势，来源记录在配置中。
