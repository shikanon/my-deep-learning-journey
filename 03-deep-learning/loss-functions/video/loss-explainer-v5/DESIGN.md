# V5：稳定的人物与场景道具

修复重点是人物的局部稳定性。V4 只统一了鞋底锚点；独立生成的姿势仍有头部横移、尺度变化与身体比例差异，连续播放时会抖动。V5 共用一张人物底稿，对既有素材做头部配准及受腰宽、领口位置约束的身体配准，保留嘴型、眨眼和手臂动作。头发、衣服主体和双脚使用固定像素，避免重新居中造成跳动。

完整动作库有七组、84 张透明 PNG。五组基础动作共用相同的开始、结束姿势，便于衔接。新增“思考问号”用于疑问与取舍，“教棍”用于曲线、Huber 和 SigLIP 2 老师讲解；教棍随手掌变化并被手遮挡，问号固定在头顶。道具为原生 SVG，帧图中已经包含它们，公共素材库同时保存独立道具。

库先保存到仓库根目录 `assets/手绘形象/shikanon-animation-v2/`，再逐文件同步到本视频 `assets/author-animation/`。旧 V1 图库、生成提示词、原始姿势与 V4 视频均保留。V5 没有新增图像或音频生成请求。

视频继续使用 SVG / HTML / CSS 与单一暂停 GSAP 时间轴。每帧时间为 `frame / 30`，人物按 10 fps 切换真实 PNG 帧。嘴型为节奏动画，非逐音素口型。进度条、字幕和人物动作均从同一时间轴取样；随机跳转不依赖浏览器的当前动画时钟。

动作预览使用 Canvas，支持七组动作、暂停、逐帧、速度和背景切换。验收分别检查原始 PNG 稳定区域、时间轴选帧，以及新编码 MP4 的实际人物区域；仅检查锚点配置或不同帧的像素变化，不能证明抖动已修好。
