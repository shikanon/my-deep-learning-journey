# V6 人物动作设计

儿童彩铅作者形象沿用既有原图。新版嘴型固定为自然闭嘴微笑，眼睛也沿用同一参考纹理；头部可作为整体轻点或歪头，嘴型本身不张合、拉伸或切换。主要动作由手势、左右脚轻移、教棍和问号表现。

## 动作与场景

- 讲解：开掌和轻微点头；开场展示数据时让手引导注意力。
- 指向：徒手指向评分卡、回答卡；曲线、Huber 和 SigLIP 2 老师持教棍，教棍跟随手掌。
- 思考：托腮与轻微歪头；疑问场景加头顶问号。前景手可以覆盖下巴，不覆盖嘴部。
- 轻步：用于“优化器负责更新参数”，左右脚交替小幅轻抬，表示向更好的参数迈一步。
- 领悟：双手握拳与轻微重心变化；用于概念总结。
- 挥手：招手并轻移重心；用于项目片尾。

身体主体、比例与放置锚点固定。头部围绕领口转动，最大幅度 2.5°；关节动作使用平滑函数，首尾回到同一中立姿势。没有按各帧外包围框重新居中。序列帧 20 fps；成片 30 fps，使用同一确定性时间轴，随机跳转可以重建相同画面。

配色、字幕、章节进度、82 组图解与 320 字/分钟的作者参考配音沿用现有内容。片尾采用作者挥手、项目名称、GitHub 作者名和文字关注提示，不展示二维码；星星轻弹呼应点亮 Star。公开动作库 V3 与视频素材逐文件保持一致；视频工程、分镜及检查文件统一留在 video 子目录。
