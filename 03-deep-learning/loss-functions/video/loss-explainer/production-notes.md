图中平方损失、Huber、交叉熵均按公式生成。曲线上的移动点分段沿函数移动；负对数曲线的标记使用对数空间采样，避免用直线穿过曲线。Focal 粒子的大小只作相对影响示意，精确的损失乘法权重在图上标出。二维表示空间、梯度方向与 VESPO 条形为教学示意。

主转场为 0.42 秒纵向推页，同步移动保留两个场景间的边界；相关主题用先淡出文字、再揭示新场景的短转场，避免两套文字同时覆盖。动画通过暂停的 `window.__timelines["main"]` 驱动，可按时间重现。

## 配音、字幕与字体

原计划使用 Seed Audio 分段保持音色；第三段生成返回 HTTP 402（付费 / 额度相关错误）。最终全片统一改用 Microsoft `zh-CN-YunxiNeural` 中文合成解说，通过 `edge-tts 7.2.8` 生成，并按同一 1.20 倍速、保留音高的方式处理。

字幕由实际生成语音的词边界生成，随音频变速等比例调整；原文标点被恢复。脚本逐场景断言配音词文本与原稿一致。DPO、VESPO 在朗读输入中使用中文读音，在字幕中显示标准缩写。字幕提供可编辑的独立 SRT。

中文使用系统冬青黑体简体中文（Hiragino Sans GB），等宽字由 HyperFrames 解析为 JetBrains Mono。最终渲染时 3 个字体面均加载成功。系统字体仅通过本地引用使用；在其他操作系统重新渲染时，可将 `style.css` 中的中文字体替换为当地可用的中文黑体或自行部署的开放字体。

## 验收证据

- 固定数值实验已执行：MSE 最优常数 6，MAE 最优常数 3；交叉熵、Focal 权重、标签平滑与正文吻合。
- 原创 SVG 共 7 张，已栅格化查看；视频的关键帧与成片抽帧均已查看。
- 完整 `hyperframes check`：静态检查、浏览器运行、版面和对比度检查均为 0 错误、0 警告。对比度检查覆盖 5 个时间点、96 个文本块。
- 运行时检查：745 个 tween，其中 138 个时长至少 150 ms；无无限循环。121 个字幕中点与 17 个场景中点均核验只有正确目标可见，未发现失败。
- 配套旧版 animation-map 脚本依赖当前 CLI 未提供的 `@hyperframes/producer`。因此使用 CLI 的 keyframes 源码映射，并直接检查 Studio 中实际运行的 GSAP 时间线；动态选择器无法由源码映射完整解析，运行时核验是更强的依据。
- FFprobe：7515 个视频帧；音视频时长均为 250.5 秒。
- FFmpeg 全片解码：退出码 0，无解码错误。
- 成片音频测量：综合响度 −15.18 LUFS，真峰值 −1.56 dBTP，响度范围 2.8 LU；无峰值超过 0 dB 的削波。
- 最后一条字幕为“独立评估检验实际结果。”，结束于 247.996 秒；结尾画面保留至 250.5 秒。
- 浏览器成片播放：从 0 秒开始正常速度、开启声音播放至结尾；最终 `currentTime = duration = 250.5`，`ended = true`，`readyState = 4`，无媒体错误。

本地详细结果位于 `qa/`，包括 `check.json`、`runtime-motion-audit.json`、`media-probe.json`、关键帧与成片缩略图。大型音频、视频和 QA 媒体按仓库规范排除在 Git 之外。

## 重新生成

需要 Python、Node.js ≥ 22、FFmpeg 和 FFprobe；在线生成配音时需能访问 Microsoft Edge 的语音服务。可在项目目录的虚拟环境安装 `requirements.txt`，已有配音素材时可直接运行后面的步骤。

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python generate_speech.py
python3 build_timeline.py --speed 1.20
python3 make_effects.py
python3 build_composition.py
npm run check
npm run render -- --quality high --fps 30 --workers 4 --strict --output renders/loss-functions.mp4
```

在线服务、字体和浏览器平台可能变化；应对新渲染重新执行检查。文章插图与数值实验无第三方 Python 依赖，分别运行 `../../examples/make_figures.py` 和 `../../examples/loss_lab.py`。

编辑预览使用 [HyperFrames Studio](http://localhost:3096/#project/loss-explainer)。本次背景预览服务已通过 `preview --status` 验证；其他环境可运行 `npx --yes hyperframes@0.8.78 preview --background --port 3096`。
