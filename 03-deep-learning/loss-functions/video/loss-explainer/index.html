17 / 17带走这三个问题

你怎么扣分，AI 就怎么学

你怎么扣分，AI 就怎么学完整推导、文献和实验见配套文章
同样把猫认成狗，
一台人工智能只是有点拿不准，
另一台却百分之九十九确信自己正确。
它们应该扣一样的分吗？
这个问题，藏着人工智能学习的关键：
损失函数。
损失函数，就是把预测和目标之间
的差距，变成一个可以计算的数。
模型先作答，
损失函数负责扣分，
反向传播算出参数的梯度，
优化器再调整参数。
四者分工不同。
如果只统计答对还是答错，
很多小幅调整都不会改变分数，
模型就很难知道该往哪里改。
可优化的损失，
提供了更细的反馈。
但分数下降，
仍然不等于真实任务一定变好。
损失函数没有一个统一的发明者。
早在一八零五年，
勒让德公开发表最小二乘法，
处理天文测量中不一致的观测。
一八零九年，
高斯进一步给出概率解释。
这条思路后来走进机器学习。
最简单的扣分方式，
是把误差平方。
错一点，罚一分；
错三点，罚九分。
这就是均方误差的核心：
大错误更受重视。
注意，多条样本还需要取平均。
现在，让模型用同一个数字预测这
五个数。一、
二、三、四，
还有二十。平方误差最小的答案是
平均数六；绝对误差最小的答案是
中位数三。只换扣分规则，
最佳答案就变了。
一九六四年，
彼得·胡伯提出经典的稳健估计方法。
小误差继续平方，
大误差改成线性增长。
它像给异常值的影响装上限速器，
同时保留零点附近的平滑性。
阈值怎么设，
依然要看数据。
分类时，我们常用交叉熵。
只看模型给真实类别的概率，
再取负对数。
给猫百分之九十，
损失约零点一一；
给猫百分之一，
损失约四点六一。
它惩罚的是错误的概率判断。
但识别一张图片，
可能遇到海量容易判断的背景。
二零一七年的焦点损失，
给交叉熵乘上一个权重。
真实类别越容易被认对，
权重越小。这样，
简单样本就不会淹没难题。
难题也可能是错标签，
不能一味加码。
标签平滑则调整目标概率。
在三个类别里，
用零点一的平滑强度，
猫的目标从百分之百变成约百分之九十三，
其他类别分到一点概率。
它帮助缓和过度自信，
但并不保证校准更好。
当我们想学会找相似图片，
损失还能奖励关系。
让同一张猫的两个视图靠近，
让不匹配的图片远离。
对比学习把配对问题变成学习信号。
正负样本选得不好，
也可能把本来相似的东西推开。
如果模型同时预测类别和深度，
就要合并多个损失。
但一个数值大，
不代表它一定更重要。
各项单位、权重和梯度方向，
都会影响谁主导学习。
加权求和，背后其实是一种取舍。
历史不是新公式不断淘汰旧公式。
一九八六年，
反向传播的代表论文推动神经网络
学习；后来有处理难样本的焦点损失，
有连接图片和文字的对比学习，
再有直接学习答案偏好的方法。
问题变了，评分规则也跟着变。
二零二三年的直接偏好优化，
也叫DPO，
把更喜欢和更不喜欢的回答组成一对。
在参考模型约束下，
直接调整相对偏好。
它简化了训练流程，
可如果偏好数据本身有偏见，
模型也会学进去。
近期研究一边组合多种目标，
让视觉语言模型既会匹配也会定位；
另一边研究大模型强化学习，
怎样给旧策略生成的答案合理加权。
二零二六年的VESPO，
就是在平衡重要性权重和训练稳定性。
九月还有研究，
把分类和聚类一起写进招聘诈骗检测
的损失。它目前是一篇预印本，
在特定公开数据集上验证。
值得关注，但新的论文，
并不自动等于通用的最好方法。
选择损失函数之前，
先问三件事：
我们究竟怕哪一种错？
数据里有没有异常和错标签？
训练分数，能不能代表真实效果？
记住：损失函数定义学习方向，
独立评估检验实际结果。
