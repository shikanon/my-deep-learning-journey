# 手绘小课堂 · 视觉与动效约定

## Style Prompt

参考用户提供的 40 秒本地动画：温暖纸张、低饱和色块、铅笔双线轮廓、小角色沿解释路径运动。主角“豆豆”是一只珊瑚红的圆角小机器人，配小天线、腮红、眼睛和短腿。采用奶油色画纸和蓝绿、黄、珊瑚色蜡笔；标题、刻度、公式保持清晰中文黑体。每个教学环节用“原情况 → 可见操作 → 结果”三个以上动作解释，不把静态卡片的进场当作全部动画。

## Colors

- 纸张 `#FFF7E4`；内页 `#FFFCF3`。
- 铅笔 / 主文字 `#46392F`；辅助文字 `#66574A`。
- 珊瑚红 `#ED826A`：错误、异常值、主角。
- 蓝绿 `#73A6A3`：目标、匹配、改善。
- 暖黄 `#EDCD74`：尺子、关注点、章节强调。

## Typography

中文采用本地 Hiragino Sans GB（W3 正文、W6 标题），通过明确 PostScript 名称声明。文字使用完整字形，不故意歪斜公式。标题 72px，图解正文 34–42px，核心数值 56px；字幕 48px。手写感来自不规则边框、短笔触和便签纸，不牺牲中文可读性。

## Motion

主转场为 0.50 秒纸页横推；进入新大章时使用 0.60 秒圆形展开。纸张轮廓描线、正负观测向中间靠拢、平方误差组成九格面积、曲线标记沿真实公式移动、数轴显示异常值拉动平均数、音量提示缩小容易样本、匹配角色拉近与不匹配角色推开。眼睛眨动和角色小跳只占次要层级。动效由真实词时间触发；关键数值读到前不提前公布。描线 0.8–1.4 秒，过程演示 2–4 秒，结论留至少 2 秒。

## Technology

HTML / CSS 管理层级、字幕和纸张；SVG 绘制可逐笔描画的角色、路径、公式曲线、关系和数据。这是二维教学，SVG + GSAP 能逐帧精确跳转、保持文字清晰且便于修订。没有需要深度、摄像机或复杂粒子模拟的内容，因此不额外引入 Three.js / WebGL。每帧取自同一暂停时间线，手绘抖动为固定几何，不使用实时随机数。

## What NOT to Do

- 不使用“AI 合成解说”等画面角注。
- 不用粗糙滤镜扭曲曲线坐标或文字。
- 不让卡通角色、装饰或字幕遮住刻度和公式。
- 不让观众同时读四块以上内容；按解说逐步呈现。
- 不使用无限循环、随机时间、闪屏和无解释目的的粒子爆炸。
