# 教学画面改进记录

验收关注“观众能否追踪依据”，不只关注图是否出现。源画面的状态来自实际动画时间线；编码截图来自最终 MP4。

| 原来的理解障碍 | 新画面的可观察依据 | 对应小节 |
| --- | --- | --- |
| 四块结果同时出现，算数过程不明显 | 参数进入乘法，再加偏置、减目标、平方除二 | s02 |
| 切线与箭头只有方向提示 | 点沿模型曲线移动，权重与损失同步更新，小步与大步可对照 | s03 |
| 差分公式没有展示两次运行 | 两个权重分别经过预测与损失，再计算损失差与参数差 | s04 |
| 反向箭头独立于计算图 | 变量固定位置，梯度沿原边返回，局部导数紧贴对应路径 | s05、s06 |
| 反传与参数更新容易混淆 | 参数先保持原值，优化器启动后才按公式变化，再重新前向 | s07 |
| 分支贡献没有回到原变量 | 从输出沿两条原路径返回；x 收到 4 与 1，并汇总成 5 | s08 |
| 方向模式只有概念标签 | 三参数函数中，一个输入方向产生一个方向导数；单输出反向得到三个偏导 | s10 |
| 两种梯度累计难区分 | 新批次反复进入同一个缓冲区；清零与平均目标另有完整状态 | s11 |
| 显存、保留与重算都是静态词语 | 保存槽逐个占用、清空，反向需要值时从检查点重算恢复 | s13 |
| “贵的保存、便宜的重算”缺少例子 | 缓存矩阵乘法结果，丢弃后续激活，再重算 ReLU 获取求导输入 | s14 |
| 压缩取舍只剩三个标签 | 同一张量显示原值、恢复值和模型计算的差异 | s15 |

全片使用稳定颜色：蓝绿表示前向数值，珊瑚表示梯度或反向需求。保存内容用黄色槽标识。示意槽、历史网络路径与舍入压缩各自说明范围，避免把演示当作测量或论文复现。
