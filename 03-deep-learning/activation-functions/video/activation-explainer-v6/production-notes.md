# 激活函数 V6：开场画面跟随口播

[观看与下载](../README.md) · [口播与分镜](storyboard.md) · [术语读音](pronunciation-guide.md)

本次调整 V5 的开场。用“问号人物思考 → 多层神经网络 → 异或四点”的画面顺序承接口播，开场不写公式；进入异或讲解后，再用抱大铅笔 V2 逐笔写出 z = W x + b。这条公式在前两个小节只书写一次。

## 口播与画面衔接

| 实际时间 | 画面 |
| --- | --- |
| 0–1.08 秒：“你知道吗？” | 画板中放大呈现带问号的思考人物，复用作者 V3 think-question 动作 |
| 1.08 秒开始：“如果每层……” | 同一人物在 0.9 秒内移到左下讲解位置；神经网络在 0.6 秒内展开，连接上的信号持续流动 |
| 4.42 秒开始：“一百层以上” | 隐藏层数从 1 增到 128；较多层用省略号展示，避免拥挤 |
| 7.20 秒开始：“四点” | 出现四个带坐标、目标颜色的异或点；实际 W/b 决定分界线和错误计数 |
| 12.91 秒进入讲解 | 博士服教棍作者讲解；13.21–15.21 秒首次手写公式，随后公式归位、图解展开 |

公共旧版本目录退役后，日常服动作迁为 `assets/手绘形象/日常服动作序列帧/`。工程渲染直接读取 `assets/author-animation/frames/` 的透明 PNG；博士服教棍和抱大铅笔也直接读取各自 PNG 序列。迁移不修改帧像素、动作顺序或成片。

开场只使用一个作者人物，人物退场后知识卡文字再出现，避免移动路径穿过文字。标题、字幕、进度和后续 18 个小节沿用已校准的时间线。

## 素材与声音

公式书写保留用户指定的 assets/手绘形象/抱大铅笔写字-v2.zip。压缩包 SHA-256 为 `61394aa633970c0d60fcb3b87e079ed9f17ccca1ed6f21547613cabf6f2f3e46`。原始 16 张透明 PNG、8 fps、2 秒往返动作没有修改像素，统一缩放至 300×300；石墨笔尖逐帧配准到真实矢量笔画末端。17 处公式保留 V5 的进场、书写、收笔、归位和图解展开节奏。

原始手绘帧的脸部、轮廓与握笔细节仍有少量变化，不声称通过骨架或逐嘴型认证。动作、笔画和数值均由 frame / fps 确定，正反向跳帧可重建同一画面。

完整沿用 V4 修正读音后的作者配音、字幕与 19 个小节。GELU 仍读 Gaussian Error Linear Unit。未再次调用配音或图像生成服务；从最终 V6 MP4 提取 AAC 并解码为单声道 PCM，与已验收 V4 逐字节比较后，继承其 11 次独立 ASR 结果，原始报告单独保存。

## 构建与验收

在本工程目录、安装 requirements.txt 对应依赖后运行：

```bash
python3 render.py
python3 verify_delivery.py
python3 verify_motion.py
python3 verify_opening.py
python3 verify_audio_continuity.py
python3 make_opening_preview.py
python3 make_player.py
python3 serve_player.py --port 8784
```

运行环境、FFmpeg、ffprobe 和中文字体由 runtime.py 发现，支持显式环境变量配置。构建、播放和验收使用本工程的音频、时间线、素材及本地依赖。

历史工程清理前，已逐字节核对 V6 与原读音验收版本的实际 AAC 和解码 PCM。核对结果保存在 [audio-provenance.json](audio-provenance.json)，原始 ASR 结果保存在 qa/source-v4-pronunciation-asr.json。音频继承脚本使用这些已核验的哈希，无需读取已删除的历史成片。修改音频后需重新进行读音验收。

verify_delivery.py 检查实际编码、完整解码、19 个章节、130 组字幕、人物与文字边界、随机跳帧和片尾。verify_motion.py 检查 17 处公式、1360 个笔画时刻、270 个异或数值时刻、51 个实际编码书写样本，以及全部 16 个笔姿的正反向选择。verify_opening.py 核对开场的实际编码画面、口播触发顺序和唯一一次公式书写。18 秒预览直接截取最终 MP4。

浏览器验收使用同一最终哈希媒体，正常速度有声连续播放到 ended=true，再验证 19 个小节、3 个大章、进度拖动、键盘与桌面及手机排版。结果由 finalize_delivery.py 汇总到 [validation.json](validation.json)。

最终验收通过。成片 SHA-256：`d6f399950d76b571b7502f25fac4f9f329d367669359e490ebaa573bf0519555`；240.7 秒、7221 帧、1080×1920、30 fps、19 个章节、130 组字幕，完整解码无错误。正常速度、有声连续播放 240.797 秒后 ended=true，中途无跳转、暂停或缓冲，媒体及页面无错误。19 个小节、3 个大章、原生进度拖动与 4 个键盘操作通过；默认 1280×720 及 390×844 手机宽度均无横向溢出，临时尺寸已恢复。开场没有公式，首次讲解只书写一次；最终 AAC 和解码 PCM 均与已验收读音版本完全一致。详细证据见 [validation.json](validation.json) 与 qa/。
